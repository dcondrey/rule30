# Adding a clock to the boundary correction buys nothing: refuted wherever a phase-matched window pair repeats, vacuous above, for every period through 16

Date 2026-09-19. Pre-registration `PREREGISTRATION.md` (committed as `ee6953f`
before any script in this directory existed). Analysis `clocked.py`, log
`clocked.log`, record `clocked.json`; lone-seed records reused from the sibling
directory `experiments/rule30/p2-orbit-window-horizon/`. Registered outcome A
held. This proves nothing about P2; it closes the clocked local form of route 3
on the measured data.

## 1. The class and the question

`r30-p2-orbit-window-horizon-refuted-or-vacuous` refutes the time-independent
orbit-only correction `K_t - rho = h(W_r(t+1)) - lambda*h(W_r(t))` at every
`r <= 18` on the first `T = 2^20` lone-seed rows. The clocked variant

```text
K_t - rho_(t mod p) = h_((t+1) mod p)(W_r(t+1))
                      - lambda * h_(t mod p)(W_r(t)),                   (2)
```

was excluded only at `p = 4` and only at `r <= 2`, by the single pair of times
29 and 41 in `r30-qwc-period-four-clock-no-repair`. Period four is the motivated
clock, since `K` is built from period-four weights `sin(pi*j/2)`; periods 2, 3,
5, 6, 7 are controls at comparable population cuts.

## 2. Two reductions

**E1 (every `lambda`, every `rho_a`).** If `s = t (mod p)`, `W_r(s) = W_r(t)`
and `W_r(s+1) = W_r(t+1)`, both sides of (2) at `s` and `t` are the same
expression in the same two functions with the same `rho_a`, so `K_s = K_t` is
forced. A phase-matched repeated pair with unequal `K` refutes (2) for all
`h_a`, `rho_a`, and `lambda`, phase-dependent `lambda_a` included.

**E2 (`lambda = 1`, the telescoping case P2 needs).** Complete, not heuristic.
The gauge `h_a(w) -> h_a(w) + c_a` shifts the right side by
`c_((t+1) mod p) - c_(t mod p)`, so only `rhobar = (1/p) sum_a rho_a` is
identifiable. Writing `g_t = h_(t mod p)(W_r(t))`, (2) reads
`g_(t+1) - g_t = K_t - rho_(t mod p)`, which determines `g` along the orbit from
`g_0`; the orbit is a single walk, so its cycle space is generated by returns to
an already visited vertex `(t mod p, W_r(t))`, and (2) is solvable iff `g`
agrees at every such return. Each return fixes
`rhobar = (sum_(s<=u<t) K_u)/(t-s)`, since a phase-matched interval contains
each phase exactly `(t-s)/p` times.

## 3. Result

`r_pair` refutes (2) for every `h_a, lambda, rho_a`; `r_one` refutes the
`lambda = 1` case for every `rho_a`; `r_half` refutes the centred
`lambda = 1, rhobar = 1/2` case. Predictions are the registered budget law
`n + log2(p) <= 2*log2(T) - 1` with `n = 2r+3` for a pair and `n = 2r+1` for a
return, `r_one` predicted one radius below `r_half`.

Every measured horizon lies within 2 of its prediction (deviations range over
`-2 .. +1`), so outcome A held. The comparison that decides outcome B is the
orbit minus the null at the same period, which cancels whatever the prediction
formula rounds: it is within `+/-1` at every period on all three horizons,
except `r_half` at `p = 8`, where it is `-2`. The multiples of four are not
elevated.

They do sit slightly below the prediction, and the null sits below it with them
by almost the same amount (mean deviation over the three horizons: orbit `-0.75`
and null `-0.58` for `p = 4, 8, 12, 16`; orbit `+0.33` and null `+0.40` for the
controls). That pattern is the formula's, not the orbit's. At `p` a power of two
`log2(p)` is an integer, so `2r + 4 <= 40 - log2(p)` lands exactly on the
boundary with no slack, while `p = 3, 5, 6, 7, 12` carry 0.2 to 0.4 of slack and
round up; `p = 12` (`log2 = 3.585`) accordingly deviates by `0, 0, 0` alongside
`p = 6` rather than with `8` and `16`. The grouping is powers of two against the
rest, and it is a ceiling artifact that the null reproduces.

At every period the kill reaches the **last** radius at which a phase-matched
repeat exists at all, so outcome C, a radius with repeats and no refutation, did
not occur anywhere. Above that radius no phase-matched pair or vertex repeats in
`t < 2^20`, so `h_a` is a free function of time along the data and (2) is
satisfiable trivially. Four one-return edge cases behave as `p = 1` did at
`r = 19`: at `p = 1, 2` (`r = 19`) and `p = 6, 12` (`r = 17`) a single return
refutes only `rhobar = 1/2`, leaving other `rhobar` and every `lambda != 1`
unrefuted at that one radius.

The horizon is a maximum over a tail that thins by about `4x` per radius, so it
is the coarse statistic. The sharp one is the per-radius repeat population,

Per period, and not pooled: the phase-matched sets nest by divisibility, since

`2` inside `1` and `12` inside `4`. Pooling the multiples of four would count
the same pairs up to four times and the Poisson variance would assume an
independence that is not there.

## 4. What this closes

The clocked class buys locality only by spending it on the clock. On this data
the surviving corrections need `(2r+1) + log2(p)` of about `2*log2(T)` at time
`T`, at which point the vertex `(t mod p, W_r(t))` is a time label and (2)
carries no locality, exactly the conclusion
`r30-p2-orbit-window-horizon-refuted-or-vacuous` reached for the radius alone.
Period four, the one the quarter-wave weights motivate, is no better than its
neighbours. Route 3's lever "an identity valid only on lone-seed rows" is left
where that record left it: terms depending on more than one past window,
growing or off-centre windows, or sums over the half-row.

Finite evidence: `T = 2^20` only, `p <= 16`, and the match to the null is
statistical, not a theorem.

## 5. Scope, including one gap the criterion leaves

E1 is sufficient but **not complete for `lambda != 1`**. A single phase-matched
return does not refute (2) there; it determines `h_a(v)` through
`(1 - lambda^L) h_a(v) = sum ...` around the cycle of length `L`, and the
complete refutation would be two returns forcing inconsistent `h_a(v)`. The pair
criterion catches only the subset where the successor window matches too, so
part of the drop in `r_pair` with `p` is the weaker test and not only the larger
model class. E2 is complete, so the `lambda = 1` case P2 actually needs carries
no such gap.

Not covered: phase-dependent `lambda_a` in the telescoping case, where the
invariant is `prod_a lambda_a = 1` rather than `lambda = 1`; `h` depending on
more than one past window or on time non-periodically, which is vacuous on
finite data; non-centred or growing windows; half-row sums; `p > 16`; and P2
itself.
