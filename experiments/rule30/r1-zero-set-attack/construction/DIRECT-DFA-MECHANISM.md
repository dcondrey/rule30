# Direct automatic-diagram construction: mechanism and acceptance conditions

Date: 2026-09-09. Active construction attempt. This file records the mechanism
discussed in the session; it is not a claim that a Rule 30 candidate has passed.

The unknowns are a finite most-significant-bit automaton on synchronized
binary coordinate digits `(t_bit,x_bit)`, a temporal lookup clock of period
`T`, a spatial lookup clock of period `q`, and binary output lookups. The root
has a `(0,0)` self-loop, so adding common leading zeros changes no output.
The automaton defines a concrete value `U(t,x)` for every `t,x>=0`.
Its transition table is synthesized directly, rather than fixed to a Rule 90
or Rule 150 source diagram.

## The exact successful certificate

1. A finite closure proves `U(t,0)=c[t mod T]` for every `t>=1`.
2. A finite coordinate-product closure proves
   `U(t+1,x)=F30(U(t,x-1),U(t,x),U(t,x+1))` for every `t>=0,x>=1`.
3. At a clock phase `r` with `c[r]=0`, the automatic sequence
   `v(n)=U(T*n+r,1)` is proved aperiodic by the uniform automatic period bound.

For the searched clocks `T=2^a`, `v` is generated by the same `N` core states
reading time digits with spatial digit zero. The fixed low coordinate suffix
`(r,1)` becomes part of the output function. The spatial lookup residue is
always `1 mod q`. Thus the direct MSB period bound uses `N`, not `N*T*q`.

The conservative proved constants are `H=2^N` and
`P=2^N*lcm(1,...,N)`. An exact inequality `v(n)!=v(n+P)` at `n>=H` proves
aperiodicity. Any such inequality has a witness with at most
`bitlength(P)+4*N^2` digits, so this finite witness search is complete for
the specified automaton observable. Earlier runs used the valid but larger
LSD-reversal bound and a restricted witness cap; those saved results retain
their original scope.

## Why this supplies an actual full diagram

The right half-plane and centre in conditions 1–2 have a unique left
extension. Starting at column zero, recursively define

```text
U(t,x-1) = U(t+1,x) XOR (U(t,x) OR U(t,x+1)),
          x=0,-1,-2,...,  t>=0.
```

At each spatial step the required right columns already exist at every time.
This enforces the Rule 30 equation at the current column. Together with
condition 2 it defines a full diagram on `t>=0,x in Z`. Its initial row is
`x -> U(0,x)`; forward determinism reproduces the constructed diagram.

If the zero-set neighbour were eventually periodic, its restriction to the
arithmetic progression `T*n+r` would be eventually periodic too. Condition 3
contradicts that. This would meet the requested generic diagram kill criterion.
It would not identify the initial row with the lone seed, nor by itself
disprove a statement explicitly restricted to lone-seed diagrams.

## Exact coordinate closure

The local-rule checker reads the four synchronized coordinate pairs

```text
(t,x-1), (t,x), (t,x+1), (t+1,x).
```

It tracks their four core states, the three prefix differences
`(t_plus-t,x_minus-x,x_plus-x)`, and the lookup residues. The differences
must remain in `{0,1}`, `{-1,0}`, and `{0,1}`, respectively. Leaving these
ranges makes the required final differences unreachable for every suffix.
At final differences `(1,-1,1)` the four outputs must be a valid Rule 30
quadruple. Every reached state has an actual finite coordinate witness;
closure under all admissible digit tuples covers all integer coordinates.
Negative spatial coordinates are unnecessary here because of the separate
left-extension construction.

## Kill conditions and limits

* A failed output equality or local gate rejects that candidate and supplies
  an actual coordinate constraint for the next solver iteration.
* An exhausted finite product with no failure certifies the relevant
  all-coordinate identity. A product-state cap is **unknown**, not success.
* A checked UNSAT proof excludes precisely the stated automaton size, lookup
  clocks, symmetry constraints, and observable-witness predicate. A restricted
  witness cap must remain visible in that statement.
* A time or iteration cap is **unknown**, not a class exclusion and not an
  R1 obstruction accepted as a final result.
* No finite gate sample, long trace, or observed lack of a period is a success
  condition. A candidate needs all three exact certificates above.

State relabelling is a valid symmetry: breadth-first first-appearance numbering
preserves the represented diagram. For Rule 30, requiring a nonzero centre
clock is also necessary: an eventually zero centre makes
`r(t+1)=r(t) OR U(t,2)`, so `r` becomes constant. This condition is not imposed
on the Rule 90 control. Temporal or spatial clock rotations are not assumed
to preserve the chosen core-state bound.

## Independent verification required for a candidate

Rebuild the finite closures independently and check them with the frozen Rule
30 truth table. Extract an actual initial right row for numeric forward
comparison, use unchanged `numeric_rho` when the centre phase is alternating,
and check the full finite left extension against the unchanged ladder engine.
Run unchanged `controls.rule90_control`; the framework already admits the
actual Rule 90 lone-seed diagram as a positive control. The OR constraints in
condition 2 supply the Rule 30-specific obligation.
