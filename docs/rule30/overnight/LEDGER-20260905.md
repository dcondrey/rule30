## PROVED

**1. The left depth `k` of the R7 ladder cannot affect its accepting tail
system.  It can only affect reachability.**
File: `experiments/rule30/r1-zero-set-attack/RESULTS-R7-WITNESS-EXTENSION.md`
section 6.

*Lemma.*  `ladder.step_window` uses the derived columns for exactly two things:
returning `col_0` and `col_{-1}`, and running the wedge/edge checks.  The wedge
checks are skipped once `cnt >= saturate`.  Since `diff_q` forces
`x_min <= -1`, every column that left depth `k > 1` adds lies below `-1` and so
feeds *only* the wedge checks.  Therefore the successor relation at
`cnt >= saturate` does not depend on `k`.

*Verified, not assumed.*  Every state of the accepting SCC carries
`cnt == saturate` exactly (rule 30 at `k = 2,4,6`: `cnt` values `{7},{11},{15}`
against `saturate = 7,11,15`; rule 90 the same).

*Consequence.*  Adding left depth can never produce an EMPTY verdict by
destroying the accepting tail; the only route left is disconnecting it from the
initial state.  That residual is a reachability question the Lemma does not
cover, and it is closed by measurement rather than proof: `empty: false` at
every `k = 1..7`.  Note the sweeps cap at `max_states = 3,000,000` and `k = 7`
plain already reached 1,439,333, so `k = 8` will likely cap — **a cap returns
INCONCLUSIVE, not EMPTY, and must not be read as unreachability.**
This upgrades `RESULTS-ladder-rung0.md`
section 3's *measured* `k`-independence to a structural one — the same upgrade
rung 1's Corollary 2/3 made for the pin.  All three R7 levers now have proofs
behind their closure rather than sweeps: left depth (here), the pin (rung 1),
and `Q` (rung 0 section 6).
