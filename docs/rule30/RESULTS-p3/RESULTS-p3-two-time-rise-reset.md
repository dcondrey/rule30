# Two-time high-field transport controlled by rising edges

Date: 2026-09-14. **The high field of B squared depends on the intermediate
low field only through its rising edges. Each rising edge resets the
remaining high-field carry, giving an exact last-rise/range-parity query.**
A corrected C-boundary version gives such a high-field query for **both
parities of the actual center column**. The final low field, when needed
for continued full evolution, still requires the intermediate low field.

This isolates a reduced control field in an exact temporal composition.
The saved [B-squared kernel](RESULTS-p3-bitplane-temporal-squaring.md) already
evaluates B squared in one spatial scan. The result here therefore does
not establish a faster B-squared implementation, an all-scale closure, or
an improved P3 complexity bound.

## 1. The complementary-factor cancellation

Work over F2. Write the input digits of Y as D_i+2H_i, and put

```
Z=D+H,  A=low(BY), C=high(BY),
p=low(B²Y), q=high(B²Y).
```

Let S be the spatial right shift with zero padding, and let
L_a=I+diag(a)S. The exact Gray identity in the
[two-affine-scans report](RESULTS-p3-two-affine-scans.md) and the high-field
inverse of the second B step give

```
Z=L_A C,
C=L_(1+A) q+A.                                  (1)
```

These involve the actual intermediate field A; no independent replacement
or completed history is inserted. Define

```
rho=A(1+SA),
rho_0=A_0, rho_i=A_i(1+A_(i-1)) for i>=1.         (2)
```

Direct operator multiplication gives

```
L_A L_(1+A)=I+S+diag(rho)S²,
L_A A=rho.
```

Consequently the complete high-field relation is

```
Z=q+Sq+rho(1+S²q).                               (3)
```

This is an identity of one-sided fields and of every finite prefix. The
coefficient of S has become constant. All remaining dependence on A in
this relation is through rho.

## 2. Hard-core control gives a first-order reset scan

Consecutive entries of rho cannot both be1. At a site i with rho_i=1,
equation (3) at i-1 therefore says
Z_(i-1)=q_(i-1)+q_(i-2). Substitution at i eliminates the older carry.
With q_-1=Z_-1=0, the resulting uniform rule is

```
q_i=Z_i+(1+rho_i)q_(i-1)+rho_i(1+Z_(i-1)).       (4)
```

Thus rho_i=0 propagates the preceding carry by XOR with Z_i, while
rho_i=1 resets it to Z_i+Z_(i-1)+1. At i=0 the same formula gives
q_0=Z_0+rho_0 directly; no negative-time or negative-site value is inferred.

For a requested position i, if rho has no1 at positions0 through i, then

```
q_i = XOR_(j=0..i) Z_j.
```

Otherwise, if k is the last position at most i with rho_k=1, then

```
q_i = 1 + XOR_(j=max(0,k-1)..i) Z_j.             (5)
```

Only the last rise and the displayed input parity are needed once the
control and input fields are supplied. This does not make their
construction free.

## 3. Both output fields and the two distinct origin conventions

From the old fields, the actual intermediate A can be generated by the
Gray low-field scan

```
A_i=D_i+Z_(i-1)+(1+Z_(i-1))A_(i-1),
A_-1=1, Z_-1=0.                                 (6)
```

The value A_-1=1 belongs to the B scan boundary. In contrast, definition
(2) uses a **zero-padded** copy of A to mark its first rise: rho_0=A_0,
not A_0(1+1). These conventions serve different operations and must not be
interchanged.

After computing q by (4), the complete final low field is

```
p_i=A_i+q_(i-1)+(1+q_(i-1))p_(i-1),
p_-1=1, q_-1=0.                                 (7)
```

Equations (2), (4), (6), and (7) are an exact forward two-time mechanism
for every input Y. Only the high-field calculation has discarded the
run-ending information in A. The low-field calculation has not.

For a supplied final endpoint p,q, the intermediate low field is also
locally recoverable from the single-step inverse:

```
A_0=p_0+1,
A_i=p_i+(p_(i-1) OR q_(i-1)) for i>=1.            (8)
```

Substituting (8) into (3) recovers a factorized form of the already proved
local inverse B-squared kernel. Thus no intermediate row needs to be
generated to check (3) from a supplied final endpoint; generating that
endpoint from the original input is a separate task.

## 4. An actual slice transfers the remaining information

If Z is identically zero and A_0=1, equation (4) gives q=1^infinity:
the origin resets to1 and every later reset has that same value. Equation
(7) then gives, including the origin,

```
q=1^infinity, p=1+A, p+q=A.                     (9)
```

The next Gray field retains the **complete** intermediate A. Simplifying
the high output has not erased that field from the continued dynamics.

This occurs on the actual zero orbit. At time0, Z=0 and A=1^infinity,
giving B²(0)=2^infinity. At time4, the saved whole-ray certificate gives
B⁴(0)=(03)^infinity. Here D=H=(01)^infinity and again Z=0. Four updates
of the carry in (6), returning to its starting phase, give
A=(1001)^infinity. Formula (9) gives q=1^infinity and
p=(0110)^infinity, exactly the saved B⁶(0)=(2332)^infinity.

The complete rays are retained in the
[two-channel artifact](../../experiments/rule30/p3-b-two-channel-block.json).
These examples use its existing certificates and the stated four-phase
carry identity; no new orbit is regenerated.

## 5. The C boundary and actual center queries of both parities

The same bitplane equations define C with the distinct virtual output
boundary (low,high)=(0,1). For this paragraph set

```
A=low(CY), Cmid=high(CY), q=high(C²Y), Z=D+H,
rho=A(1+SA),
```

again using zero padding only for S and rho. Let e_i denote the field
with its only1 at position i. Retaining the actual high boundary1 gives

```
Z=L_A Cmid+A_0 e_0,
Cmid=L_(1+A)q+A+(1+A_0)e_0.
```

Since L_A e_0=e_0+A_1e_1, the corrected identity is

```
Z=q+Sq+rho(1+S²q)+e_0+rho_1 e_1.               (10)
```

In particular its first two sites and subsequent scan are

```
q_0=H_0,
q_1=Z_1+q_0,
q_i=Z_i+(1+rho_i)q_(i-1)+rho_i(1+Z_(i-1))
     for i>=2.                                  (11)
```

The first equality also uses A_0=1+D_0, the actual low origin update of
C. The rises at positions0 and1 do not reset this scan. If the last rise
k at or before i with k>=2 exists, the answer is still
1+XOR Z_[k-1..i]. If none exists, it is
H_0+XOR Z_[1..i], with an empty XOR when i=0. The coefficient at site2
is valid because (10) makes Z_1=q_1+q_0 regardless of rho_1; subsequent
resets use the same hard-core argument as before.

The proved [actual center identities](RESULTS-p3-actual-b-query.md) give,
for h>=1,

```
c_(2h)   = high(digit_(h-1)(C^(h+1)(0))),
c_(2h+1) = high(digit_(h-1)(B^(h+2)(0))).         (12)
```

Thus both cases use the high-only control reduction:

| Center query | Old input Y | Intermediate low A | Last-rise rule |
|---|---|---|---|
| c_(2h) | C^(h-1)(0) | low(C^h(0)) | (11), rises k>=2 |
| c_(2h+1) | B^h(0) | low(B^(h+1)(0)) | (5), rises k>=0 |

Both are queried at i=h-1. On the actual C orbit, the baseline H_0 in
(11) equals (h-1) mod2, since C complements its root digit. The cases
c_0=c_1=1 remain separate. These formulas require no final low-field
readout for either center parity. They still require the actual old Gray
parity range and the rises of the actual intermediate low field; those
are not supplied for free by (12).

## 6. Verification and cost

The [new verifier](../../experiments/rule30/p3_two_time_rise_reset.py) and
[artifact](../../experiments/rule30/p3-two-time-rise-reset.json) check the
factor cancellation, hard-core reset rule, origin, last-rise formula,
the C boundary correction, remaining low output, and actual zero-Gray slice
against independent local digit updates and the saved ray data.

Explicitly constructing A, rho, q, and p on m sites takes O(m) local
Boolean operations and O(m) stored field bits, plus index and representation
costs. Finding a last rise and evaluating a parity can be cheaper with
suitable **supplied** summaries. No bound is proved here for constructing
those summaries across actual temporal blocks. In particular no update
closing the complete dynamics on Z and rho alone, or shrinking total work
under repeated temporal doubling, has been established.
