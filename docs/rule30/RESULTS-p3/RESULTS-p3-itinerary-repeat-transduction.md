# Exact repetition-node transduction for the P3 itinerary map

Date: 2026-09-13. **The itinerary map K processes a repeated input block
using at most three distinct entering-state transductions of that block.**
The number of repetitions is handled arithmetically, without expanding
the repeated word. This is a constructive grammar operation. It does not
replace an arbitrary number of K iterates by one such operation, and no
uniformly small grammar bound under iteration is proved.

The [implementation](../../experiments/rule30/p3_itinerary_repeat_transduction.py)
and [artifact](../../experiments/rule30/p3-itinerary-repeat-transduction.json)
retain the entire eight-element monoid, its multiplication table, complete
finite-state control orbits, and a large repeated-input construction.

## 1. Exact state convention

Use the [exact itinerary conjugacy](RESULTS-p3-itinerary-conjugacy.md).
Digits are read in base4, low digit first. K starts in state C. Its three
states have output permutations

```
A: (0,3,2,1),    B: (1,2,3,0),    C: (3,2,1,0).
```

After emitting digit d, the next state is A for d=0, B for d=1, and C
for d=2 or3. The next state depends on the emitted digit. Replacing it
by the input-dependent rule from the original grouped generator changes
the map.

The ordered internal state is retained at every concatenation boundary.
If W is a finite input word, let F_W be its map on the three entering
states, and T_s(W) its full output word from state s. Then

```
F_(UV)=F_V composed with F_U,
T_s(UV)=T_s(U) T_(F_U(s))(V).                       (1)
```

## 2. An eight-element input-state monoid

Write a state map as its three images on A,B,C. The four input digits act
as

| Input digit | State map |
|---:|---|
| 0 | (A,B,C), the identity |
| 1 | (C,C,C), a reset |
| 2 | (C,C,B) |
| 3 | (B,A,A) |

The complete generated monoid is

```
I=(A,B,C),
f2=(C,C,B),       f2²=(B,B,C),
f3=(B,A,A),       f3²=(A,B,B),
constant A, constant B, constant C.                 (2)
```

These eight maps are distinct and closed under composition. Each is
generated by a word: respectively the empty word,2,22,3,33,13,12,1.
The full64-entry multiplication table is checked. For every map in (2)
and every entering state, its state orbit has transient at most1 and
period at most2. This follows directly from the displayed maps; all24
orbits are retained as finite certificates.

In particular, zeros leave the internal state unchanged. Repeated ones
reset it after the first symbol. Repeated twos eventually alternate B,C;
repeated threes eventually alternate A,B. A2 followed by a3 resets to A,
and a3 followed by a2 resets to C, even if any zeros are interposed.

The maps are not a group, despite there being eight of them. Reset maps
and rank-two maps are essential to the construction.

## 3. A proved rule for arbitrary repetition nodes

**Theorem.** For any input word W, repetition count m>=0, and entering
state s, T_s(W^m) can be constructed from at most three blocks of the
form T_a(W), using concatenation and repetition with known integer
counts. The final state is computed exactly.

Proof. Let s_i=F_W^i(s). By (2), this sequence has a transient of length
mu<=1 followed by a cycle of length p<=2. Composition (1) gives

```
T_s(W^m)=T_(s_0)(W) T_(s_1)(W) ... T_(s_(m-1))(W). (3)
```

If m<=mu, there is at most one block. Otherwise write m-mu=qp+r,
0<=r<p. Construct the first mu blocks; concatenate the p cycle blocks
and repeat that combined word q times; then append its first r blocks.
Only mu+p<=3 distinct entering states are needed. The final state is
s_m, obtained from the same orbit using integer division and remainder.
This proves the rule without discarding the entering state or resetting
the state between repeated copies.

The implementation supports a straight-line grammar with digit,
concatenation, and Repeat(W,m) nodes. It stores F_W and the expanded
length at each node. It computes a transduction recursively and memoizes
the pair (node, entering state). Concatenation uses the actual middle
state from (1); a repetition uses (3). Nested repetitions are combined by
the exact identity (W^a)^b=W^(ab).

For an input grammar with s reachable nodes, a single K pass has at most
3s distinct node/state subqueries. Each creates only a constant number of
concatenation or repetition nodes. Thus the number of structural grammar
operations is O(s), with the additional costs of exponent and length
arithmetic, input-grammar construction, and output-node interning charged.
The bit lengths of those integers are not treated as constant.

This is closure of the grammar representation under one transduction.
It is not closure in a fixed finite collection of output words, and it
does not bound the grammar sizes s_0,s_1,... after many K passes. Repeating
the construction L times costs the sum of those paid pass costs. An
exponent m in an input Repeat node and an exponent L in K^L are different
operations.

## 4. Two passes do not close the simplest eventual-tail family

As a bounded exact discriminator, compose two K state machines. For
each of the four constant input streams and each of the nine entering
state pairs, the complete reachable state orbit has transient at most2
and period at most2. The36 certificates include every transition up to
the first return. Hence the assertion holds for the entire infinite
constant stream, rather than just a checked prefix.

The family consisting of constant and alternating eventual tails is
nevertheless not closed under two passes. There is an actual orbit
counterexample:

```
K^4(0) = (02)^infinity,
K^2((02)^infinity) = 03(2012)^infinity.             (4)
```

The eventual output block2012 has primitive period4, since its two
halves differ. A complete composed-machine cycle certificate proves each
identity in (4). For the second, the state includes both entering states
and the phase of the periodic input02. Its transient is2 and cycle
length4. Keeping that input phase is necessary.

This reuses the actual sixth-iterate itinerary associated with the
earlier [triangular-core counterexample](RESULTS-p3-triangular-core-power.md).
It does not generate a new center prefix. It refutes this particular
bounded-period tail family, while the more general repetition grammar
from section3 remains exactly closed under a pass.

## 5. Checks and remaining algorithmic requirement

The verifier checks all12 local transitions against independent
arithmetic permutation formulas, all64 monoid products, all24 state
orbits, and105 finite repeated-input controls. It also builds the output
for the input block203 repeated10^30+1 times, retaining the grammar and
sampling exact digits by a separate binary powering of the three-state
block map. No word of that expanded length is generated. The artifact
records both input and newly constructed nodes, transduction calls,
integer-valued exponents, and the final boundary state.
This directed construction uses eight initial nodes, six new nodes, and
eleven distinct node/state transductions.

The structural theorem already explains why the large input repetition
can be handled cheaply. Its finite measurements are implementation
controls, not evidence that K^L(0) has a small grammar uniformly in L.
A useful powering theorem still needs to control successive grammar
growth or combine many K passes while constructing their required
boundaries. The present operation supplies an exact component for such
an algorithm and does not establish a sublinear singleton center query.
