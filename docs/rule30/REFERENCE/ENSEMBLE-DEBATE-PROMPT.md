## 1. The prize problem, and where this sits

Rule 30 is the elementary CA `x'_i = x_(i-1) XOR (x_i OR x_(i+1))`.

**P1 (the open prize problem):** the centre column of Rule 30 from a lone seed
is not eventually periodic, for any period.

**PT2** is the `p = 2` rung of P1: for every nonzero finite configuration `y`,
`Tr_0(y) != Tr_0(F^2(y))`, where `Tr_0` is the centre-column trace. Period one
is already closed unconditionally for every nonzero finite configuration. PT2 is
one rung, not P1.

There is a proved implication chain ending in PT2. Every arrow in it is proved
except one, and there are two independent candidate routes to supply that arrow.
This document is about **route 2**, with route 1 summarised in §7 because a
cross-route idea is welcome.

Critically: `x'_i = x_(i-1) XOR (x_i OR x_(i+1))` is *left permutive*, and so is
Rule 90 (`x'_i = x_(i-1) XOR x_(i+1)`). Rule 90's lone-seed centre column **is**
eventually periodic. So **any argument that uses only left permutivity or
expansivity is known to be insufficient** — it would prove a false statement
about Rule 90. This is the "Rule 90 filter" and it is the single sharpest
constraint on this whole problem. Every proposal must survive it, and must say
where it uses something Rule 30 has and Rule 90 lacks.

The one Rule-30-specific ingredient available in the machinery below is stated
exactly in §2.4: `Phi(2, .) = Phi(3, .)`, which is where the `OR` enters and
which is vacuous for Rule 90.

## 2. The object, defined completely

### 2.1 States, symbols, the carry action

Symbols and states are both integers `0..3`, read as two bits: for `s`,
write `hi(s) = s >> 1` and `lo(s) = s & 1`.

The **carry action** is the exact Rule 30 leftward-forcing step. It comes from
solving `x'_i = x_(i-1) XOR (x_i OR x_(i+1))` for `x_(i-1)`:

```
carry(symbol, state):
    a, b = symbol >> 1, symbol & 1
    c, d = state  >> 1, state  & 1
    return 2 * (c XOR (a OR b)) + (d XOR (c OR a))
```

`FORWARD[symbol]` is the 4-tuple `(carry(symbol, 0), ..., carry(symbol, 3))`:

```
FORWARD[0] = (0, 1, 3, 2)      FORWARD[1] = (2, 3, 1, 0)
FORWARD[2] = (3, 2, 1, 0)      FORWARD[3] = (3, 2, 1, 0)
```

Each is a permutation of `{0,1,2,3}`. `INVERSE[s]` is the inverse permutation of
`FORWARD[s]`.

```
swap(s)      = 2 * (s & 1) + (s >> 1)
BOUNDARY     = INVERSE[3] = (3, 2, 1, 0)        # bitwise complement
cone_local(left, right) = INVERSE[swap(left)][right]
```

The four **local transforms** `L(left) := INVERSE[swap(left)]`, as 4-tuples
indexed by `right`:

```
L(0) = (0, 1, 3, 2)
L(1) = (3, 2, 1, 0)
L(2) = (3, 2, 0, 1)
L(3) = (3, 2, 1, 0)
```

The group generated by `{L(0), L(1), L(2), L(3), BOUNDARY}` under composition
has **order 8 and is non-abelian** (it is D8). This is verified, not assumed.

### 2.2 The forcing, step by step

Fix a **source word** `W` of length `n` over the alphabet `{1, 2}` subject to
the **hard-core** constraint: no factor `11`. (There are `Fib(n+2)` such words.)

Fix a **constant tail** `c` in `{2, 3}`.

Build an `edge` (a tuple of states) and an `endpoint` list:

```
append_edge(edge, previous, value):
    out = [BOUNDARY[value]]
    if edge is empty:  return (out[0],)
    out.append(cone_local(previous, out[0]))
    for m in 2 .. len(edge):
        out.append(cone_local(edge[m-2], out[-1]))
    return tuple(out)
```

Initialise `edge = ()`, `endpoint = []`, and feed in `n` zeros followed by the
`n` symbols of `W`:

```
for value in [0]*n + list(W):
    edge = append_edge(edge, endpoint[-1] if endpoint else None, value)
    endpoint.append(value)
```

Then run `2n` **forced steps**. At each step, the **newest-cut permutation**
`A` is the composite

```
newest(edge, previous):
    A = BOUNDARY
    for left in (previous,) + edge[:-1]:
        A = compose(L(left), A)          # L applied on the LEFT of A
    return A

compose(after, before)[s] = after[before[s]]
```

and the forced symbol is `A^(-1)(c)`:

```
extension = []
maps = []
for _ in range(2n):
    A = newest(edge, endpoint[-1])
    symbol = inverse_of(A)[c]
    maps.append(A); extension.append(symbol)
    edge = append_edge(edge, endpoint[-1], symbol)
    endpoint.append(symbol)
```

`maps[j]` is written `A_j`. Note the composition order and the `A^(-1)(c)`
convention are not stylistic: they were calibrated against an independent
bit-sliced implementation and reproduce it exactly (see §5).

### 2.3 Survival, and the target

The **survival length** is how long the forced continuation stays hard-core:

```
survival(W, c):
    previous = W[-1]
    for index, value in enumerate(extension):
        if value not in (1,2) or (previous == value == 1):  return index
        previous = value
    return len(extension)
```

Write `s_2(W)` and `s_3(W)`. The live conjecture, which is what the whole route
needs, is

```
    s_2(W) <= n        and        s_3(W) <= n + 1                     (1)
```

for every nonempty hard-core `W` of length `n`. `(1)` suffices for the scale
separator (for tail 2, `n < 2n`; for tail 3, `n+1 < 2n` when `n >= 2`, and
`n = 1` is checked directly), and the separator closes both constant-tail modes,
the rank-zero separator, and the nonconstant period-two centre trace. **`(1)` is
the missing arrow.**

`(1)` is verified exhaustively for all hard-core `W` through length 22, and by a
deterministic certificate through length 23.

### 2.4 Where the OR lives

`carry` reads its symbol only through `(a OR b)` and `a`. Therefore

```
FORWARD[2] == FORWARD[3]        i.e.   Phi(2, .) = Phi(3, .)
```

and equivalently `L(1) == L(3)`. This collapse is **the** Rule-30-specific fact
in the machinery. For Rule 90 the analogous carry is
`c' = c XOR b`, `d' = d XOR a`, whose four transforms are all distinct, whose
group is **abelian of order 4** (translations), and for which the collapse is
vacuous.

## 3. The reduction: C3

For each `k` in `0..n`, define **scenario `k`** as the word `W` with its first
`k` symbols replaced by `0`:

```
W^(k) = 0^k W[k:]        W^(0) = W,   W^(n) = 0^n
```

Run the whole forcing of §2.2 on `W^(k)` and write `A_(j,k)` for its row-`j`
newest-cut permutation. Define the **sensitivity set** of row `j`:

```
S_j = { k in 0..n-1  :  A_(j,k) != A_(j,k+1) }
```

A row `j` is **legal** exactly where the following claim asserts something: for
tail 2, every `0 <= j < s_2`; for tail 3, only the nonfinal rows `j + 1 < s_3`
(tail 3's final row is exempt).

> **C3.** For every nonempty hard-core `W`, every tail `c`, and every legal row
> `j`:  `max S_j >= j`.

**C3 implies (1)**, in two lines. Tokens are `0..n-1`, so `max S_j <= n-1`. For
tail 2 every row `0 <= j <= s_2 - 1` is legal, so `s_2 - 1 <= n - 1`. For tail 3
the legal rows are `0 <= j <= s_3 - 2`, so `s_3 - 2 <= n - 1`. Exactly `(1)`,
with no slack given away.

**Equivalent restatement (C3'').** `max S_j >= j` says the sequence
`k -> A_(j,k)` is non-constant on `k in [j, n]`, and `k = n` is the all-zero
word, so C3 is:

> Among the suffixes of `W` of length at most `n - j`, at least one moves the
> row-`j` newest-cut permutation off its all-zero value.

Contrapositive form, which is the one to attack: **no nonempty hard-core `V` of
length `L = n - j` has every nonempty suffix affine-neutral at row `j`.**

### 3.1 Everything measured about C3

- **C3 holds on all 44,205 legal rows** of every hard-core word through length
  20, both tails. Zero failures.
- Slack `max S_j - j` ranges 0 to 18. The minimum, 0, is attained on **exactly
  two rows in the whole corpus**: `W = 121` and `W = 221`, both tail 3, row 2,
  both with `S_j = {0, 1, 2}`. Both are `n = 3` with `s_3 = 4 = n + 1`, the two
  words that attain the bound `(1)`. **Any proposed proof that fails on those
  two words is false.**
- Measured to length 18: `max(s_2 - n) = -1` and `max(s_3 - n) = +1`. So tail
  2's bound in `(1)` is never met, tail 3's is met (first at `W = 121`).
- Nobody has checked C3 beyond length 20. **It could be false.** The
  cost is `Fib(n+2)` words times an `O(n^2)`-ish per-word check.

## 4. A separate, proved fact you may find useful or misleading

There is a related scan in the same project — the queue step, a different object
from §2 — whose transition table is

```
Q(0) = (0,1,3,2)   Q(1) = (3,2,1,0)   Q(2) = (2,3,1,0)   Q(3) = (3,2,1,0)
```

over a normalized alphabet `{0,1,2}` (the symbol quotient `3 -> 1`). Define
`sig_A(w) = (full trace of intermediate states from entering state q)_(q=0..3)`.

**Theorem (proved, this project).** `sig_A` is injective on same-length words,
for every length. Proof: each `Q(a)` is a permutation, so the shared-prefix map
is a bijection and the four entering states arrive at position `i` covering all
four states; and `Q(a) != Q(b)` for distinct normalized `a, b`, so some arriving
state separates them. Two finite checks on a 4x4 table.

Consequences: the block right-congruence is the identity, the block monoid is
free on three generators, and **no bounded lossless summary of an interior block
exists at any radius, of any shape.** This closed an entire family of attempted
tools.

**Warning, and a genuine open question for the debate.** It is tempting to
conclude "the dynamics has unbounded memory, therefore C3 is hopeless". That
inference is *not* valid as stated, and identifying whether some sharper version
of it *is* valid would itself be a result. The free-monoid theorem quantifies
over all of `{0,1,2}^L`. C3 quantifies only over the **nested chain**
`V, 0V[1:], 00V[2:], ..., 0^L` — a single path, of length `L`, not an
exponential family. A property can hold along every nested-suffix path and still
fail to be finite-state on the free monoid. Whether that gap is real here, or
whether the free-monoid result does secretly obstruct C3, is open and worth
arguing about.

## 7. Route 1, in brief, for cross-route ideas

An independent route reaches the same missing arrow through a quantity
`gamma(n)`: the claim `gamma(n) >= 1` is equivalent to "no reachable forcing
state at length `n` survives `n+2` forced rows". The plan was: the words
attaining maximum survival are few (single digits per `n`), they were believed
to be "clean periodic adversaries" — prefixes of purely periodic hard-core
sequences of bounded period, or single-defect words `2^a 1 2^b` — and extinction
on a *finite list of periodic rays* would be a finite automaton or a
one-dimensional recurrence rather than an exponential census.

buys, since the finite-ray argument needed the source side.

Also relevant: a first-moment / `phi/4` bound cannot close `gamma(n) >= 1` —
the hard-core transfer matrix has spectral radius `phi`, so `lambda < 2` is
vacuous; the bound is tight below a threshold depth and off by roughly 300 at
extinction; and fibers stabilise at a small constant instead of shrinking, so
past depth `~n/2` the argument would need a fiber smaller than one.

## 8. The questions, in priority order

**Q1 (main).** Prove or refute C3: for every nonempty hard-core `W` of length
`n`, tail `c in {2,3}`, and legal row `j`, `max S_j >= j`. Equivalently
(C3''): no nonempty hard-core `V` of length `L` has every nonempty suffix
affine-neutral at the relevant row.

Constraints any proof must satisfy, all of them non-negotiable:
- it must survive `W = 121` and `W = 221`, tail 3, row 2, where slack is 0;
- it must not prove `C12` or `C14` along the way, since both are false;
- it must say where it uses `Phi(2,.) = Phi(3,.)` (or another Rule-30-specific
  fact), because otherwise it proves the same statement for Rule 90 and the
  Rule 90 filter kills it;
- it must not rely on a bounded summary of an interior block (§4).

**Q2.** Characterise the **shortest affine-neutral nonempty suffixes**: for a
given row, the minimal `V` such that every nonempty suffix of `V` leaves the
row-`j` map at its all-zero value. That list is the obstruction. A proof of C3
amounts to showing every such `V` is illegal on a legal row. Is there structure
in it? Is it even nonempty?

**Q3.** Make the Rule 90 filter well-posed. What is the correct Rule 90 analogue
of *this* setup — its own invariant SFT for the forced language, its own
constant-tail values replacing `c in {2,3}` — such that C3 can be scored on it
and the comparison means something? Or argue that no faithful analogue exists,
which would itself be informative about how Rule-30-specific the object is.

**Q4.** The non-abelian D8 structure of the newest-cut group is the visible
difference from Rule 90's abelian order-4 group. Is non-commutativity the actual
mechanism behind C3? Can you write a statement of the form "C3 holds for any
left-permutive rule whose newest-cut group is non-abelian" — and check it
against a third rule to avoid a two-point fit?

**Q5.** Is there a *different* reduction of `(1)` that avoids C3 entirely? The
greedy-frontier statement implies C3 which implies `(1)`; the chain was
weakened once already. Can it be weakened again, or replaced?

**Q6 (route 1).** Given that extremal *sources* are not a bounded-period family
but extremal *continuations* keep small periods, is there a continuation-side
formulation of `gamma(n) >= 1` that recovers a finite object?

## Appendix A: reference implementation

Self-contained Python. Reproduces the project's sensitivity sets and survival
exactly (checked to length 12). Use it to test any claim you make.

```python
from itertools import product

def carry(symbol, state):
    a, b = symbol >> 1, symbol & 1
    c, d = state >> 1, state & 1
    return 2 * (c ^ (a | b)) + (d ^ (c | a))

FORWARD = tuple(tuple(carry(s, st) for st in range(4)) for s in range(4))

def inverse_of(t):
    out = [0] * 4
    for state, image in enumerate(t):
        out[image] = state
    return tuple(out)

INVERSE  = tuple(map(inverse_of, FORWARD))
BOUNDARY = INVERSE[3]

def swap(s):                 return 2 * (s & 1) + (s >> 1)
def cone_local(left, right): return INVERSE[swap(left)][right]
def L(left):                 return INVERSE[swap(left)]
def compose(after, before):  return tuple(after[before[s]] for s in range(4))

def append_edge(edge, previous, value):
    out = [BOUNDARY[value]]
    if not edge:
        return (out[0],)
    out.append(cone_local(previous, out[0]))
    for m in range(2, len(edge) + 1):
        out.append(cone_local(edge[m - 2], out[-1]))
    return tuple(out)

def newest(edge, previous):
    A = BOUNDARY
    for left in (previous,) + edge[:-1]:
        A = compose(L(left), A)
    return A

def force(word, c):
    """Return (forced extension, [A_j]) for one source word and tail c."""
    n = len(word)
    edge, endpoint = (), []
    for value in [0] * n + list(word):
        edge = append_edge(edge, endpoint[-1] if endpoint else None, value)
        endpoint.append(value)
    extension, maps = [], []
    for _ in range(2 * n):
        A = newest(edge, endpoint[-1])
        symbol = inverse_of(A)[c]
        maps.append(A); extension.append(symbol)
        edge = append_edge(edge, endpoint[-1], symbol)
        endpoint.append(symbol)
    return tuple(extension), maps

def survival(word, extension):
    previous = word[-1]
    for index, value in enumerate(extension):
        if value not in (1, 2) or (previous == value == 1):
            return index
        previous = value
    return len(extension)

def sensitivity(word, c):
    """Return ({j: S_j}, survival) for the zero-prefix scenario chain."""
    n = len(word)
    runs = [force((0,) * k + tuple(word[k:]), c) for k in range(n + 1)]
    surv = survival(word, runs[0][0])
    return {j: {k for k in range(n) if runs[k][1][j] != runs[k + 1][1][j]}
            for j in range(surv)}, surv

def hard_core(n):
    return [w for w in product((1, 2), repeat=n)
            if all(w[i:i+2] != (1, 1) for i in range(n - 1))]

def c3_census(max_length):
    rows = fails = 0
    for n in range(1, max_length + 1):
        for w in hard_core(n):
            for c in (2, 3):
                graph, surv = sensitivity(w, c)
                for j in range(surv):
                    if c == 3 and j + 1 >= surv:   # tail 3's final row is exempt
                        continue
                    rows += 1
                    if not graph[j] or max(graph[j]) < j:
                        fails += 1
                        print("C3 FAILS", "".join(map(str, w)), c, j, sorted(graph[j]))
    return rows, fails
```
