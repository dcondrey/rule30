# Exact eventual-period test for arbitrary-radix automatic candidates

Date: 2026-09-09. Intermediate construction machinery; **R1 remains open**.

This extends the [MSB binary lemma](RESULTS-r1-msb-automatic-period-bound.md)
to any integer radix `b >= 2`. It permits a separate base-three construction
search, including a period-three centre clock. It does not assert that any
Rule 30 diagram has an automatic presentation.

## 1. Uniform statement (`U`)

Let `u(n)` be generated by a deterministic, most-significant-digit-first
automaton with at most `N` states, finite output alphabet, and a leading-zero
self-loop at its initial state. Put

```text
H = b^N,
P = b^N lcm(1,2,...,N).
```

Then `u` is eventually periodic if and only if

```text
u(n) = u(n+P) for every n >= H.
```

Unreachable and observationally equivalent states are allowed. The proof
uses the number `n <= N` of reachable states in the minimal padded machine.

### Proof

Suppose the eventual tail has least period `p`, and let `v` be its unique
purely periodic extension to all nonnegative indices. Write `p=e d`, where
every prime divisor of `e` divides `b`, and `gcd(d,b)=1`. Let `a` be the
least nonnegative integer for which `e` divides `b^a`. Thus `e` need not be
a power of `b`; this distinction matters for composite radices.

For each integer residue `r modulo p`, define the residual function

```text
R_r(w) = v(b^|w| r + value_b(w)).
```

All distinct such functions occur as automaton states after sufficiently
large positive numerical prefixes congruent to `r modulo p`. They form a
closed set `Q_tail` of `M` states under digit transitions.

On these states, let `E_k` mean equality after every common suffix of
exactly `k` digits. The equivalences increase with `k`. Once two consecutive
equivalences coincide, every later equivalence coincides too: apply the
same successor-partition operation. `E_0` is equality of residual states.

After `a` digits the part `e` of the period has disappeared, so prefixes
with the same residue modulo `d` are `E_a`-equivalent. Different residues
modulo `d` cannot be equivalent: sufficiently long suffixes cover a full
period, and multiplication by powers of `b` is invertible modulo `d`.
Otherwise a nonzero proper residue difference modulo `d` would supply a
smaller period of `v`. Hence `E_a` has exactly `d` classes.

If `a>0` and `E_(a-1)=E_a`, comparison of prefixes `r` and `r+d`, followed
by every suffix of length `a-1`, would give `b^(a-1)d` as a period of `v`.
Those suffixes and prefixes cover every nonnegative numerical argument.
This contradicts the definition of `a` and minimality of `p`. Therefore
the equivalence chain has `a` strict steps, and

```text
M >= a+d.
```

In particular `a <= N-1`, `d <= N`, and `p` divides `P`.

It remains to bound the exceptional prefix. A positive-prefix path cannot
repeat a state outside `Q_tail`: pumping the intervening nonempty word
would produce arbitrarily large positive prefixes whose residual is still
outside `Q_tail`, contradicting eventual periodicity. Consequently a
canonical numerical prefix enters `Q_tail` after at most `n-M` digits.
The residual `R_r` reached at a prefix with value `x` must have `r=x modulo
d`. This follows by comparing sufficiently long suffixes, which reach only
the periodic tail, and again using the invertibility of `b modulo d`.
After a further `a` digits, the remaining discrepancy modulo `e` is also
removed. Thus agreement with `v` holds once the canonical length is at
least `n-M+a <= N-1`; the deliberately looser threshold `b^N` is safe.
Since `p|P`, the claimed equality follows. The converse is immediate. QED.

For the independent LSD regression, the corresponding kernel argument
also extends: a decimation by `b` reduces positive `b`-height `a` by one
along some child, a purely coprime period produces that many distinct
shifted tails, and a finite exceptional set accepted by an `N`-state
padded LSD machine has no canonical word longer than `N` (pumping before
the final nonzero digit would give infinitely many exceptions). These give
the same conservative `H,P` for that machine's own state count. The
reversed machine may have more states; the regression deliberately uses
its own bounds.

## 2. Complete finite product (`C` plus finite-state proof)

The new
[radix checker](../../experiments/rule30/r1-isolated-column/radix_automatic_period_bound.py)
reads `n,n+P` in parallel from high to low digits. It tracks their two DFA
states, the carry into the already read part, position in the fixed radix
expansion of `P`, and the significant length of `n`, capped at `N+1`.
For each guessed lower carry it requires

```text
n_digit + P_digit + carry_in = shifted_digit + b*carry_out.
```

Both carries are in `{0,1}` in every radix. The fixed expansion permits
arbitrarily many initial zero digits. Its first and last carries are zero.
Every accepted product path is a genuine pair `n,n+P` with `n>=H`, and
every such pair has a path. Product states therefore suffice to enumerate
all possible endpoint-state pairs. With `L` digits in `P`, the safe state
bound is `2 N^2 (L+2)(N+2)`. A representative integer is saved for each
endpoint pair; its size is not used as a simulation cutoff.

The synthesis-facing API is `endpoint_pairs(delta, start=0)`, which returns
`H`, `P`, the product closure count, and records with `states` and `witness`.
`mismatch` labels those pairs with an output function.

The base-three two-state machine `delta=((0,0,1),(1,1,0))`, outputs `(0,1)`,
counts digits equal to two modulo two. Its exact mismatch is `n=20` at
`H=9,P=18`; the two outputs at 20 and 38 differ. Its product closes at 80
states. The displayed digit formula is separately checked at 4,096
indices. The uniform theorem and the exact mismatch certify aperiodicity;
the 4,096-index comparison only checks the implementation of that formula.

lone-seed neighbour passes its aperiodicity test and agrees with frozen
forward evolution for 256 samples / 66,048 cells. Unchanged

## 4. Scope

This is a rule-independent certificate for a specified automatic sequence.
A Rule 30 construction still needs independently verified gates at every
coordinate, a periodic centre, and an aperiodic observable on a zero phase.
No such base-three model is claimed here. No frozen engine was edited.
